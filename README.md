## Apresentação do projeto

A Byte Burger é uma loja fictícia de hambúrgueres criada
como projeto de aprendizagem de desenvolvimento web.

A loja apresenta um cardápio com produtos e preços,
permitindo que o usuário simule uma compra.

## Produtos

| Produto | Preço |
|---|---:|
| Byte Classic | R$ 22,90 |
| Byte Bacon | R$ 27,90 |
| Byte Double | R$ 32,90 |
| Batata Byte | R$ 14,90 |

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html no navegador.
4. Clique em "Simular compra".
5. Informe as quantidades desejadas.

## Testes realizados

- Teste de compra com vários produtos.

- Teste de cálculo do valor total.
- Teste com quantidade inválida.

## Dificuldade encontrada e aprendizado

Uma das dificuldades foi desenvolver a lógica de
cálculo dos produtos e entender como utilizar
as funções prompt(), Number() e alert().

Com o desenvolvimento do projeto, aprendi a utilizar
JavaScript para receber informações do usuário,
realizar cálculos e apresentar resultados.
